# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's
private vulnerability reporting: [Report a vulnerability](https://github.com/firsttris/schreibzeug/security/advisories/new)
(the repository's **Security** tab → **Advisories** → **Report a vulnerability**).

Say what an attacker can do, what they need for it (an account, a share, a link, a file they made),
and how to reproduce it, ideally with the smallest request or file that shows it. The answer
comes in the advisory.

## Supported versions

Only the latest release gets security fixes: the newest image `tristanteu/schreibzeug:latest`
(also `ghcr.io/firsttris/schreibzeug`) and the desktop app of the newest
[release](https://github.com/firsttris/schreibzeug/releases). Update to it before reporting
([updates](https://firsttris.github.io/schreibzeug/installation.html#updates)).
